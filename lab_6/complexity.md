# Анализ сложности алгоритмов

`n` - длина исходной строки, `m` - длина искомой подстроки. Ниже приведены оценки для худшего случая без учета чтения, разбора и вывода данных. Сравнение символов и операция `Map` по одному символу считаются за **O(1)**

Суффиксное дерево - сжатый бор всех суффиксов. В конец строки дописывается терминатор `$`, которого нет во входе, поэтому ни один суффикс не является префиксом другого. Ребро хранит пару индексов `[start, end)` в общей строке, а не копию символов. Узел создается только в точке ветвления и в листе

## 1. Суффиксное дерево

Для строки длины `n` в дереве `n + 1` суффикс (вместе с `$`). Каждый внутренний узел имеет не меньше двух детей, листьев `n + 1`, поэтому узлов

`v <= 2 * (n + 1) - 1 = 2n + 1`

Ребер `e = v - 1 <= 2n`

- **Построение:** **O(n^2)**. Суффиксы вставляются по одному, как слова в бор. Суффикс длины `L` сравнивает не больше `L` символов. Сумма длин суффиксов строки длины `n + 1` равна `(n + 1) * (n + 2) / 2`
- `has`**:** **O(m)** - один проход по подстроке вдоль ребер. При успехе ровно `m` сравнений символов
- `count`**:** **O(m + s)**, где `s` - число узлов в поддереве места, где закончилась подстрока. Каждое вхождение - лист этого поддерева. `s <= v`, поэтому **O(m + n)**
- `lcp(i, j)`**:** **O(d)**, где `d` - длина общего префикса двух суффиксов: путь от корня до расхождения
- **Память:** **O(n)** на узлы, ребра и одну копию строки с терминатором. Ведущий множитель по узлам - `2n + 1`

Бор суффиксов без сжатия ребер заводит узел на каждый символ каждого различного префикса суффикса. Различных подстрок бывает до `n * (n + 1) / 2`, и столько же узлов. Сжатое дерево укладывается в `2n + 1` узел: память **O(n)** против **O(n^2)** у бора суффиксов. Множитель `2` - это лист и не более одного внутреннего узла на суффикс

## 2. Наибольший палиндром

Строится суффиксное дерево строки `S + # + reverse(S)`. Длина этой строки вместе с `$` равна `N = 2n + 2`

Палиндром с центром в позиции `i` - общий префикс двух суффиксов этого дерева:

- нечетная длина: `lcp(i + 1, 2n - i + 1)`, длина палиндрома `2 * d + 1`
- четная длина, центр между `i - 1` и `i`: `lcp(i, 2n - i + 1)`, длина `2 * d`

`#` и `$` останавливают сравнение на границе `S` и `reverse(S)`. Берется максимум по `n` центрам. При равной длине остается самый левый: центры просматриваются слева направо, обновление только при строго большей длине

- **Время построения:** **O(n^2)**. Сумма длин суффиксов не больше `N * (N + 1) / 2 = (2n + 2) * (2n + 3) / 2 = 2n^2 + 5n + 3`. Ведущий член - `2n^2`
- **Время поиска центра:** **O(n^2)**. Выполняется `2n` вызовов `lcp`. На строке из одинаковых символов сумма радиусов имеет порядок `n^2 / 2` сравнений
- **Память:** **O(n)**. Узлов `v <= 2 * N - 1 = 4n + 3`. Ведущий множитель - `4n` узлов плюс одна строка длины `2n + 2`

Отдельно хранить все суффиксы `S` и `reverse(S)` стоило бы `N * (N + 1) / 2` символов, то есть те же `2n^2 + 5n + 3`. Дерево хранит символы один раз
