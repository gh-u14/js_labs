# Анализ сложности алгоритмов

`n` - суммарная длина добавленных слов (число символов)
`L` - длина одного слова
`v` - число узлов бора
`|S| = 33` - размер русского алфавита 

Ниже приведены оценки для худшего случая без учета чтения, разбора и вывода данных. Операция `Map` по одному символу считается за **O(1)**

Словарь хранится бором (trie). Слово - путь от корня; конец слова помечен флагом узла. Общий префикс хранится один раз. Исходные строки после вставки не сохраняются

## Операции

- `add`**:** **O(L)** - один проход по символам. На символ одно чтение `Map` и, если перехода еще нет, одна запись
- `addMany`**:** **O(n)** - сумма длин слов списка. Сначала проверяется весь список, затем идет вставка
- `has`**:** **O(L)** - один проход по символам до конца слова или до первого отсутствующего перехода. Префикс без флага конца слова ответом «есть» не считается
- `size`**:** **O(1)**

## Память

Узел хранит `Map` только из тех букв, которые реально встретились. Число ребер `e = v - 1`. Каждый новый символ создает не больше одного узла, поэтому

`v ≤ n + 1`, память **O(v) = O(n)** в худшем случае (общих префиксов нет)

Если хотя бы два слова делят префикс, одни и те же узлы используются повторно и `v - 1 < n`. Пример: «кот» и «коты» - 7 символов, 5 узлов (корень, к, о, т, ы), 4 ребра

Точное хранение произвольного набора строк в худшем случае требует **O(n)** памяти: иначе нельзя отличить все возможные словари. Оценка **O(v)** этой нижней границы достигает, когда префиксы не пересекаются

## Ведущие множители

`|S| = 33` - константа, поэтому **O(33 · n) = O(n)** асимптотически. Множитель 33 при этом остается, его и сравниваем

- Узел с массивом из 33 ссылок занимает **O(m)** памяти, `m = 33 · v ≤ 33 · (n + 1)`. Почти все ячейки пустые: у слова языка ветвление гораздо меньше 33
- `Map` хранит одну запись на ребро. Память **O(e) = O(v)**, множитель алфавита в оценку не входит. Это строго меньше `33 · v`: на тех же узлах массив держал бы в 33 раза больше ячеек, чем число ребер
- Поиск ребенка перебором букв или списка детей дал бы время **O(t)**, `t = 33 · L` на слово и `t = 33 · n` на список. Прямой доступ по символу убирает этот множитель: `add` **/** `has` **делают ровно L обращений к** `Map`, `addMany` **- ровно n**
